# Phase 3 — Cosmic Kitchen

Deliverable: a playable kitchen with ingredients, a mixing bowl, and gravity toggle.

## Run today (OpenCV preview)

```text
hand_tracking\run_phase3.bat
```

### What to try
1. Pinch any of the 6 ingredients and move them.
2. Release over the **Mixing Bowl** to drop them in.
3. Press **G** to toggle **Zero-G** — ingredients float and drift.
4. Press **G** again to restore gravity (they fall).
5. Press **R** to reset the kitchen.

Falling when you release with gravity on is intentional.

## Unity path (when Hub is installed)

1. Open `UnityProject`
2. Menu **FOODIVERSE → Create Phase 3 Cosmic Kitchen**
3. Press **Play**
4. Run `hand_tracking\run_bridge.bat`
5. Press **G** in the Unity Game view to toggle zero-G

## Signature mechanic

Space affects cooking: gravity changes how ingredients behave while you prepare food.
