# Phase 4 — Cooking & recipe discovery

Deliverable: heat/cool, stir, and discover recipes from ingredient pairs.

## Run

```text
hand_tracking\run_phase4.bat
```

Window title should say **Cooking (Phase 4)**.

## How to cook

1. Pinch **exactly two** ingredients for a recipe into the bowl.
2. Set temperature if needed:
   - **H** = heat
   - **C** = cool
   - **N** = neutral
3. With an **open hand** (do not pinch), wave back and forth over the glowing bowl ring to fill STIR.
   - Backup: hold **S** to stir.
4. When stir + temp + ingredients match → the mixture transforms into a creature above the bowl
   (Ember Dragon, Grove Guardian, or Mint Current). Press **B** for the next recipe.

## Recipes

| Recipe | Ingredients | Temp | Result (creature preview) |
|--------|-------------|------|---------------------------|
| Ember Spark | Cosmic Fruit + Star-Pepper | HOT | Ember Dragon |
| Grove Bloom | Space Leaves + Crystal Sugar | any | Grove Guardian |
| Mint Current | Chocolate + Mint Crystal | COLD | Mint Current |

## Keys

| Key | Action |
|-----|--------|
| H / C / N | Heat / Cool / Neutral |
| S | Hold to stir (backup) |
| G | Gravity / Zero-G |
| B | Empty bowl back onto counter |
| R | Full kitchen reset |
| Q | Quit |

## Tips

- Stir with an **open hand** waving over the bowl — pinching stops stirring.
- Look for the blue/green ring around the bowl and the **STIRRING!** label.
- Wrong pairs still work as a mix — press **B** or **R** and try again.
- Discover all 3 recipes to finish Phase 4.
