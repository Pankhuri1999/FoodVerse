# FOODIVERSE: Cosmic Kitchen — Design Reference

Living design notes for development. Full concept lives in the project vision document.

## Core Loop

Explore → Collect → Cook → Create Life → Build → Restore

## Signature Mechanic

Space affects cooking → Cooking creates life → Life transforms worlds.

## MVP Checklist

1. One spaceship kitchen
2. One miniature edible planet
3. Hand-based interactions
4. Six ingredients
5. Three edible construction materials / structure types
6. Zero gravity + one additional physics effect
7. Three recipe-based creatures
8. One complete planetary rescue mission
9. One memorable creature transformation
10. Satisfying planetary restoration ending

## Input Architecture

Webcam / Quest hand tracking → Input interface → Unity interaction → Ingredient physics

Keep gameplay systems independent from the input source so Quest can replace the webcam later.
