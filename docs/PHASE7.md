# Phase 7 — Save the Cookie Kingdom

Deliverable: one complete rescue mission connecting collect → cook → build → creature ability → restore.

## Run

```text
hand_tracking\run_phase7.bat
```

## Mission stages

| Stage | What to do |
|-------|------------|
| 1 Distress | Wait a moment or pinch to begin |
| 2 Collect | Pinch **Cosmic Fruit** + **Star-Pepper** into the bowl |
| 3 Cook | Press **H** to heat, wave **open hand** over bowl (or hold **S**) |
| 4 Build | Pinch **Cookie Bridge** onto the glowing GAP |
| 5 Ability | Ember **auto-follows** your hand (green tether) — hold over **ICE GATE** ~0.7s to melt (or pinch / **E**) |

If Ember ever seems stuck, press **5** to jump to the ability stage and test following.
| 6 Restored | Kingdom saved — citizens appear |

## Keys

| Key | Action |
|-----|--------|
| H | Heat bowl (cook stage) |
| S | Hold to stir (backup) |
| R | Restart mission |
| Q | Quit |

## Design loop

Explore → Collect → Cook → Create life → Build → Restore

This is the MVP “first ten minutes” fantasy from the design doc, focused on Ember Dragon + Cookie Kingdom.
